# tsurubami

一个基于 Tauri 2 + Vite 的桌宠应用。  
祂会常驻桌面、保持透明置顶、根据时间和你的交互切换状态，并用短句、提醒陪着你。

## 当前功能

- 透明、无边框、始终置顶的桌宠主窗口
- 长按拖拽移动位置，并自动记住上次停留位置
- 点击角色触发不同台词，不同时间段会有不同语气
- 自动说话与状态切换：待机、移动、说话、睡眠等
- 独立设置窗口，可调整：
  - 自动说话
  - 活跃度（低 / 中 / 高）
  - 深夜安静模式
  - 提醒功能
  - 麦克风互动与灵敏度
  - 点击穿透
  - 微妙互动（实验性）
- 点击穿透模式与保底恢复快捷键：`CmdOrCtrl + Shift + R`
- 托盘菜单：打开设置、重置位置、恢复交互、退出
- 可隐藏桌宠并通过桌面按钮或托盘重新呼出
- 内置可编辑提醒系统：支持一次性提醒、每日提醒、启停、编辑、删除与本地持久化
- 可选开启麦克风互动，根据环境声音触发轻微“听见了”或“被吓到”的反应
- 可恢复演示提醒，并从设置页手动触发测试提醒
- 粒子特效、轻微浮动和少量不可预测的互动反馈

## 技术栈

- Tauri 2
- Vite 5
- 原生端：Rust
- 前端：原生 JavaScript + HTML + CSS

## 项目结构

```text
.
├─ index.html                 # 主桌宠窗口
├─ settings.html              # 设置窗口
├─ src/
│  ├─ app.js                  # 应用启动与事件总线
│  ├─ main.js                 # 主窗口入口
│  ├─ settings-window.js      # 设置窗口逻辑
│  ├─ pet/                    # 桌宠状态机、行为与交互
│  ├─ dialogue/               # 台词池与选择逻辑
│  ├─ reminder/               # 提醒数据与调度
│  ├─ menu/                   # 主窗口菜单与设置入口
│  ├─ behavior/               # 用户行为追踪与分析
│  ├─ weird/                  # 实验性“微妙互动”
│  ├─ time/                   # 时间语境
│  ├─ storage/                # 窗口位置持久化调用
│  ├─ bubble/                 # 气泡显示
│  ├─ styles/                 # 主窗口与设置窗口样式
│  └─ assets/                 # 角色资源
└─ src-tauri/
   ├─ src/main.rs             # 窗口、托盘、原生命令
   └─ tauri.conf.json         # Tauri 配置
```

## 环境要求

- Node.js 18+
- Rust stable
- 系统依赖请按 Tauri 官方文档安装

## 安装

```bash
npm install
```

## 开发

```bash
npm run tauri dev
```

这会启动 Vite，并拉起 Tauri 桌面应用。

如果只想调前端页面，也可以运行：

```bash
npm run dev
```

## 构建

```bash
npm run tauri build
```

当前配置里 `bundle.active` 为 `false`，默认会先走可执行程序构建流程，不直接产出安装包。

## 交互说明

- 单击角色：触发互动台词
- 长按角色：进入拖拽
- 右键角色：打开主窗口内的快捷菜单
- 设置页可切换点击穿透；进入后若点不到桌宠，可用 `CmdOrCtrl + Shift + R` 恢复
- 托盘左键可唤回主窗口，托盘菜单可打开设置或恢复交互
